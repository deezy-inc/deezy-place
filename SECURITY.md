# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly by emailing:

**danny@deezy.io**

Please include as much detail as possible: a description of the issue, steps to reproduce, and the potential impact. Do not open a public GitHub issue for security reports.

If unable to reach via email, try reaching Danny at https://x.com/dannydeezy, but please do not publicly state that there is a security issue in deezy-place specifically.

We will acknowledge your report as soon as possible and keep you informed as we investigate and address the issue. Thank you for helping keep deezy and its users safe.
